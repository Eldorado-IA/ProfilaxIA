Os arquivos de entrega são registros históricos. O documento do buscador descreve a versão de terminal em BioC; o backend web usa XML JATS. As contagens dos slides correspondem a uma etapa diferente da planilha presente no código. As diferenças são descritas nos documentos de referência.

`entrega_manifest.json` registra nomes de origem e hashes dos documentos preservados. `data_manifest.json` identifica a planilha e os artefatos numéricos.
